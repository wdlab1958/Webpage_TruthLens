ADAG (Adversarial Detection Assessment & Governance)는 5개의 적대적 공격 모듈로 구성된 Red Team 시스템입니다. Red Team이 탐지 시스템을 공격하고, Blue Team(탐지 시스템)이 방어하는 Feedback Loop를 통해 탐지 견고성을 지속적으로 향상시킵니다.

5개 적대적 공격 모듈

  • #55 BiologicalSignalInjector — rPPG Agent 대상: 합성 PPG/HRV 신호 주입, 눈 깜빡임 패턴 위조
  • #56 GANFingerprintDisruptor — Visual Agent 대상: FFT 마스킹, 카메라 ISP 시뮬레이션, JPEG 후처리로 GAN 핑거프린트 교란
  • #57 TemporalConsistencyManipulator — Temporal Agent 대상: 미세운동 주입, 모션블러 추가, 조명 동기화로 시간적 일관성 위장
  • #58 TextHumanizer — Document Agent 대상: 통계노이즈, 오타, 스타일 변동 주입으로 AI 생성 텍스트 인간화
  • #59 ADAG Harness (5-Layer) — 전체 시스템 대상: HarnessRunner + TraceLogger + Evaluator 통합 프레임워크

Harness 5-Layer 구조

  • Layer 1: 공격 시나리오 생성 (Attack Scenario Generator)
  • Layer 2: 공격 실행 (Attack Executor)
  • Layer 3: 탐지 결과 수집 (Detection Result Collector)
  • Layer 4: 성능 평가 (Performance Evaluator)
  • Layer 5: 피드백 반영 (Feedback Loop Integrator)

운영 방식

Celery Beat을 통해 매일 02:00에 ADAG 적대적 테스트를 자동 실행하고, 03:00에 결과 백업을 수행합니다. Detection Error Rate(DER)가 10% 미만으로 낮아지면 조기 종료됩니다. 발견된 취약점은 자동으로 탐지 모델의 재학습에 반영됩니다.

#6 Graph-of-Thought (GoT)

Custom DAG(Directed Acyclic Graph) 기반의 6단계 조건부 분기 라우팅 시스템입니다. 기존의 선형적 사고(Chain-of-Thought)를 넘어 복잡한 추론 과정을 그래프 구조로 표현하여 비선형적, 병렬적 사고를 가능하게 합니다.

6단계 조건부 분기

  • Stage 1: 입력 미디어 유형 분류 (영상/이미지/음성/문서)
  • Stage 2: 모달리티별 1차 분석 노드 선택
  • Stage 3: 1차 결과 기반 심화 분석 경로 분기
  • Stage 4: 교차 모달리티 검증 필요 여부 판단
  • Stage 5: 불확실 구간 진입 시 AutoGen 토론 트리거
  • Stage 6: 최종 증거 통합 및 Verdict 생성

Chain-of-Thought과의 차이

CoT는 순차적으로 하나의 경로만 따라가지만, GoT는 여러 갈래의 추론 경로를 동시에 탐색하고 각 경로의 결과를 비교/통합할 수 있습니다. 이를 통해 딥페이크 분석처럼 다양한 관점이 필요한 문제에 더 적합한 추론을 수행합니다.

추론 구조: DAG 기반 비선형 | 분기: 6단계 조건부 | 병렬 탐색: 지원

#7 DSPy Prompt Optimizer

Stanford DSPy 프레임워크를 활용한 자동 프롬프트 최적화 시스템입니다. 수동 프롬프트 엔지니어링의 시행착오 없이, 12개 Signature를 데이터 기반으로 자동 최적화합니다.

12개 Signature

TruthLens 파이프라인의 각 단계(전처리, 시각 분석, 오디오 분석, 생체 분석, OCR, Fusion, XAI 설명, Verdict 생성 등)에 사용되는 LLM 프롬프트를 Signature로 정의하고, 학습 데이터를 통해 최적의 프롬프트를 자동으로 도출합니다.

최적화 방식

  • Bootstrap Few-Shot — 성공 사례에서 자동으로 Few-shot 예시를 추출
  • MIPRO (Multi-prompt Instruction Proposal Optimizer) — 여러 프롬프트 후보를 동시에 평가
  • Metric-Guided — F1 Score, Accuracy 등 정량 지표 기반 최적화

장점

LLM 모델이 변경되거나(예: llama3.2 → Qwen2.5) 탐지 파이프라인이 업데이트될 때, 수동으로 프롬프트를 재작성할 필요 없이 자동으로 최적의 프롬프트를 재학습합니다.

#8 LlamaIndex RAG

LlamaIndex + ChromaDB 기반의 위협 인텔리전스 시스템입니다. RAG(Retrieval-Augmented Generation) 기법으로 과거 분석 이력, 위협 정보, 유사 사례를 검색하여 현재 분석의 판정에 참고 자료로 제공합니다.

핵심 기능

  • 유사 사례 검색 — 현재 분석 대상과 유사한 과거 분석 결과를 벡터 유사도 검색으로 조회
  • 위협 인텔리전스 — 최근 발견된 딥페이크 공격 패턴, 새로운 생성 모델 정보를 축적
  • 컨텍스트 강화 — 검색된 유사 사례를 LLM의 컨텍스트에 주입하여 판정 근거를 강화
  • 지속적 학습 — 새로운 분석 결과가 자동으로 벡터 DB에 인덱싱되어 지식 베이스가 성장

기술 구성

  • LlamaIndex — 문서 인덱싱 및 검색 파이프라인
  • ChromaDB — 벡터 임베딩 저장 및 유사도 검색
  • nomic-embed-text — Ollama 기반 텍스트 임베딩 모델

활용 시나리오

SHAP 분석 판독법

SHAP 분석의 폭포(Waterfall) 차트는 기저값(Base Value = 0.5)에서 시작하여 각 탐지 모듈이 최종 판정을 FAKE(+) 또는 REAL(-) 방향으로 얼마나 밀었는지를 순서대로 누적하여 보여줍니다. 빨간색 바는 FAKE 방향, 파란색 바는 REAL 방향으로의 기여를 나타냅니다.

무결성 보장

SHA-256 해시 체인으로 보호되는 감사 로그와 타임스탬프가 포함되어 보고서의 무결성과 생성 시각이 법적으로 검증 가능합니다. 해시 체인 상태가 "VALID"이어야 보고서의 무결성이 확인된 것이며, "BROKEN"이면 법적 효력이 없습니다.

XAI Deep Dive

판정의 근거를 설명 가능한 AI(XAI) 기법으로 심층 분석하는 고급 분석 도구입니다. "왜 이 영상이 FAKE로 판정되었는가?"라는 질문에 시각적이고 정량적인 방식으로 답합니다. 한국 AI 기본법 제15조의 AI 판단 근거 설명 의무를 직접적으로 충족시키는 핵심 도구입니다.

분석 도구

  • SHAP 폭포 차트: 각 모듈의 판정 기여도 (양방향 바 차트). 기저선(Base=0.5)에서 출발하여 각 모듈이 FAKE(+) 또는 REAL(-) 방향으로 얼마나 밀었는지를 시각화
  • Grad-CAM++ 히트맵: 모델이 주목한 영역의 열지도. 파란색→초록→노란색→빨간색으로 의심 강도가 높아지며, 빨간색이 얼굴 경계에 집중되면 합성 흔적의 강력한 증거
  • 베이지안 불확실성: 각 모듈의 판정 신뢰 구간 (평균, 표준편차, 90% CI). 신뢰구간이 좁을수록 확실한 판단, 0.5를 포함하면 근거로 사용하기 어려움
  • 모듈 기여도: 각 탐지 모듈의 기여 비율 (바 차트)

  • Stage 5: 위험도 평가 — 탐지된 특성의 신뢰도와 위험 수준 산정
  • Stage 6: 최종 귀속 — 후보 모델 범위를 좁혀 최종 귀속 판정

Proactive Defense

원본 미디어에 비가시적 워터마크(Invisible Watermark)를 삽입하여, 향후 딥페이크로 변조되더라도 원본 여부를 과학적으로 증명할 수 있는 사전적 보호 도구입니다.

6종 적대적 방어 기법

  • PGD (Projected Gradient Descent) — 반복적 경사 하강법 기반 적대적 섭동 생성
  • FGSM (Fast Gradient Sign Method) — 빠른 단일 스텝 적대적 섭동
  • C&W (Carlini & Wagner) — 최적화 기반 고정밀 공격
  • DeepFool — 최소 섭동 경계 탐색
  • AutoAttack — 앙상블 기반 자동 공격
  • Patch-based — 지역적 패치 기반 방어

품질 보장

PSNR 40dB 이상의 고품질 설정을 적용하면 워터마크 삽입 전후를 구별할 수 없는 수준의 품질이 유지됩니다. 인간의 시각으로는 원본과 워터마크 삽입본의 차이를 감지할 수 없습니다.

Vision-Language Model 분석기의 정확도와 안정성을 대폭 개선한 6가지 핵심 수정입니다.

변경 사항

VLM 모델 교체deepseek-r1:8b (텍스트 전용) → minicpm-v:8b (비전 모델) — 이미지를 직접 이해하는 비전 모델로 교체하여 분석 정확도 향상

FIX: CrewAI Verdict (#42)

12인 전문가 합의 판정 시스템의 판정 정확도와 신뢰도를 개선하는 3가지 수정입니다.

Explainable AI (XAI)

TruthLens는 한국 AI 기본법 제15조의 "AI 판단 근거 설명 의무"를 직접적으로 충족시키는 핵심 도구입니다. "왜 이 영상이 FAKE로 판정되었는가?"라는 질문에 시각적이고 정량적인 방식으로 답합니다.

SHAP 폭포 차트 (Waterfall Chart)

기저값(Base Value = 0.5)에서 출발하여 각 탐지 모듈이 최종 판정을 FAKE(+) 또는 REAL(-) 방향으로 얼마나 밀었는지를 순서대로 누적하여 보여줍니다. 빨간색 바는 FAKE 방향, 파란색 바는 REAL 방향으로의 기여를 나타냅니다.

Grad-CAM++ 히트맵

이미지의 어느 픽셀이 판정에 결정적 영향을 미쳤는지를 시각화합니다. 파란색->초록->노란색->빨간색으로 의심 강도가 높아집니다. 빨간색이 얼굴 경계에 집중되면 합성 흔적의 강력한 증거입니다.

베이지안 불확실성 (Bayesian Uncertainty)

각 모듈의 판정 신뢰 구간을 평균, 표준편차, 90% CI로 제공합니다. 신뢰구간이 좁을수록 해당 모듈의 판단이 확실하고, 신뢰구간이 0.5를 포함하는 모듈의 결과는 판정 근거로 사용하기 어렵습니다.

증거 체인 (Evidence Chain)

판정 근거가 된 구체적인 증거 항목이 심각도(HIGH/MEDIUM/LOW)와 함께 나열됩니다. 각 증거는 해당 탐지 모듈, 점수, 판정 기여도가 함께 표시됩니다.
